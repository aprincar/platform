# Aprincar — Visual Reference Lock

A partir desta branch, os boards aprovados pelo produto definem a aparência oficial do Aprincar.

## Não negociar sem nova aprovação

1. Logo em A arredondado azul com play amarelo.
2. Wordmark Navy + Blue.
3. Mascote infantil humano/cartoon apresentado nos boards.
4. Poppins como tipografia principal.
5. UI predominantemente clara, branca e azul, com acentos amarelo/verde/coral.
6. Cards leves, radius alto, sombras discretas.
7. Home e catálogo mobile-first como nas pranchas.
8. Assets dos jogos com acabamento ilustrativo consistente.

A fidelidade deve ser avaliada pelo resultado visual e não apenas pela existência de tokens ou componentes com nomes equivalentes.
